# Top 10 Spotify Songs by artist

Thanks to Spotify API, this web application allows you to search for any artist and explore their most popular tracks.
You can view the popularity scale 0-100 about each song and open direct links to listen them on Spotify. 
Whether you're discovering new music or checking out your favorite artists, this tool makes it fast and easy.

## ⚙️ Functions
- 🔍 Search artists on Spotify
- 📕 Bookmark your favourite artist
- ⚖️ View the popularity scale of the song
- 📱 Fully responsive

## 🛠️ Technologies
- Bootstrap
- Python
- HTML
- CSS
- JavaScript

## 🚀 How-to run
- Create App on Spotify for Developers website
- Paste your CLIENT_ID and CLIENT_SECRET in .env file
- In terminal paste ```python app.py```
